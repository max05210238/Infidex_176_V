# FBX — Mesh Exports

61 files (mostly FBX, plus a few STL and DAE for metal parts). These are the author's mesh exports for viewing and editing in 3D applications other than 3ds Max.

The FBX files mirror the STL set but in a flat directory. For printing, use the STL files instead. The Kodak cone files (`Kodak_cone_base.*`, `Kodak_lens_board.*`) and metal part references (`METAL-Counter_gear.dae`, `METAL-Sprocket_gear.dae`, `METAL-Sprocket_shaft.dae`) are only available here.
