# Downloads

## Infidex_176_V_complete.zip (~20 MB)

The author's original release archive containing all project files in one download:

- All STL print files (organized by category)
- All FBX mesh exports
- Community modifications (MODS)
- Original PDF manual
- 3ds Max source file (.max)

This is the same set of files distributed across the repository, bundled for convenience. The archive was downloaded directly from [timetowaste.ru](https://timetowaste.ru) before the site's scheduled shutdown.

To download, click the file above then use the **Download raw file** button, or clone the repository.
