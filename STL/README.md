# STL — Print-Ready Parts

57 STL files organized by function. All files are the author's original exports from `Infidex 176 V_NEWEST.max`.

## Folders

| Folder | Contents |
|---|---|
| `Body/` | Body shells (top/bottom, unibody, ver2 variants) and four door options |
| `Lens mount/Focusing Helicoid/` | Recommended mount — allows real focusing. Includes Blue Dot shorter variants |
| `Lens mount/Classic Cone/` | Fixed-focus cone mount |
| `Lens mount/Tube/` | Fixed-focus tube mount |
| `Lens mount/Old Version cone for T-22 lens/` | Legacy cone for Lomo T-22 lens (from earlier model) |
| `Small parts/` | Knobs, gears, viewfinders, lens hoods, lens cap, cold shoe, pressure plate, etc. |

Print only **one** body set (top+bottom or unibody), **one** lens mount type, and **one** door variant. See [docs/PRINTING.md](../docs/PRINTING.md) for settings and orientation.
